# FraudAnalyzer AI

## 🚨 Problem Statement
Online fraud and scams through SMS, links, emails, images, and voice messages are rapidly increasing, causing financial loss and security risks for users.

## 💡 Solution
FraudAnalyzer AI is an AI-powered fraud and scam detection system that analyzes suspicious text, SMS, links, images, and voice inputs to detect potential threats and provide actionable safety guidance.

## ✨ Features
- 📩 SMS & text scam detection
- 🔗 Malicious link analysis
- 🖼 Image-based fraud detection
- 🎤 Voice message input support
- 📊 Risk score & confidence meter
- ⚠️ Scam type identification
- ✅ Safety recommendations
- 

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- AI Engine: Google Gemini API

## 🔄 How It Works
1. User enters the content (text, link, image, or voice)
2. Data is sent to the backend server
3. Gemini AI analyzes the content
4. Risk score, scam type, and  are generated
5. Results are displayed in a user-friendly dashboard
